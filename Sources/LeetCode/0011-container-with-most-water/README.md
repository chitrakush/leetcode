# 11. Container With Most Water

[LeetCode link](https://leetcode.com/problems/container-with-most-water/)

**Difficulty:** Medium
**Tags:** Two Pointers, Array
**Status:** ⬜ Not started

## Problem

You're given `n` non-negative integers `height`, where `height[i]` is the height of a vertical line drawn at index `i`. Pick two lines that, together with the x-axis, form a container — find the pair that holds the most water. (The container can't be tilted; capacity is width times the shorter of the two heights.)

**Example:** `height = [1,8,6,2,5,4,8,3,7]` → `49` (lines at index 1 and 8: width 7, height min(8,7)=7)
**Example:** `height = [1,1]` → `1`

**Constraints:** `2 <= height.length <= 10^5`, `0 <= height[i] <= 10^4`
