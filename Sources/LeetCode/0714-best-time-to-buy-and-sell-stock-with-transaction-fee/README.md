# 714. Best Time to Buy and Sell Stock with Transaction Fee

[LeetCode link](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/)

**Difficulty:** Medium
**Tags:** Dynamic Programming
**Status:** ⬜ Not started

## Problem

Given an array `prices` (price on each day) and a flat transaction `fee`, return the max profit achievable. You can make unlimited buy/sell transactions but must hold at most one share at a time (sell before buying again), and pay the fee once per completed transaction.

**Example:** `prices = [1,3,2,8,4,9]`, `fee = 2` → `8`
**Example:** `prices = [1,3,7,5,10,3]`, `fee = 3` → `6`

**Constraints:** `1 <= prices.length <= 5*10^4`, `0 <= fee < 5*10^4`
