**Tags:** Sliding Window, Array

## Problem

Given a binary array `nums`, you must delete exactly one element. Return the length of the longest run of consecutive 1's in the remaining array.

**Example:** `nums = [1,1,0,1]` → `3`
**Example:** `nums = [0,1,1,1,0,1,1,0,1]` → `5`
**Example:** `nums = [1,1,1]` → `2` (a deletion is still mandatory)

**Constraints:** `1 <= nums.length <= 10^5`, `nums[i]` is `0` or `1`
