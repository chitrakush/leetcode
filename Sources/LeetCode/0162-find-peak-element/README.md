## Problem

A peak element is strictly greater than both its neighbors (edges are treated as bordering `-infinity`). Given an integer array `nums` with no two adjacent elements equal, return the index of any peak.

**Example:** `nums = [1,2,3,1]` → `2`
**Example:** `nums = [1,2,1,3,5,6,4]` → `1` or `5` (either is valid)

**Constraints:** `1 <= nums.length <= 1000`, adjacent elements are never equal
