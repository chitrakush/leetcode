## Problem

Given two integer arrays `nums1` and `nums2`, return a two-element result where the first list holds the distinct values only in `nums1` and the second holds the distinct values only in `nums2` (order doesn't matter within each list).

**Example:** `nums1 = [1,2,3]`, `nums2 = [2,4,6]` → `[[1,3],[4,6]]`
**Example:** `nums1 = [1,2,3,3]`, `nums2 = [1,1,2,2]` → `[[3],[]]`

**Constraints:** `1 <= nums1.length, nums2.length <= 1000`, `-1000 <= nums1[i], nums2[i] <= 1000`
