# 435. Non-overlapping Intervals

[LeetCode link](https://leetcode.com/problems/non-overlapping-intervals/)

**Difficulty:** Medium
**Tags:** Array, Sorting
**Status:** ⬜ Not started

## Problem

Given an array of intervals `[start, end]`, return the minimum number of intervals to remove so that none of the remaining intervals overlap.

**Example:** `intervals = [[1,2],[2,3],[3,4],[1,3]]` → `1`
**Example:** `intervals = [[1,2],[1,2],[1,2]]` → `2`
**Example:** `intervals = [[1,2],[2,3]]` → `0`

**Constraints:** `1 <= intervals.length <= 10^5`, `-5*10^4 <= start < end <= 5*10^4`
