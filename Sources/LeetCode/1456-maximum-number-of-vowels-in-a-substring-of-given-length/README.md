# 1456. Maximum Number of Vowels in a Substring of Given Length

[LeetCode link](https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)

**Difficulty:** Medium
**Tags:** Sliding Window, Array
**Status:** ⬜ Not started

## Problem

Given a string `s` and an integer `k`, return the maximum number of vowels (`a, e, i, o, u`) contained in any substring of `s` with length exactly `k`.

**Example:** `s = "abciiidef"`, `k = 3` → `3`
**Example:** `s = "aeiou"`, `k = 2` → `2`
**Example:** `s = "leetcode"`, `k = 3` → `2`

**Constraints:** `1 <= s.length <= 10^5`, lowercase English letters, `1 <= k <= s.length`
