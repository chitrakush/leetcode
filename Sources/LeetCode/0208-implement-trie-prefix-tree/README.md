## Problem

Implement a `Trie` (prefix tree) supporting `insert(word)`, `search(word)` (exact word match), and `startsWith(prefix)` (does any inserted word begin with this prefix).

**Example:** `insert("apple")`; `search("apple")` → `true`; `search("app")` → `false`; `startsWith("app")` → `true`; `insert("app")`; `search("app")` → `true`

**Constraints:** `1 <= word.length, prefix.length <= 2000`, lowercase English letters, at most `3*10^4` total calls
