## Problem

Design a `SmallestInfiniteSet` that conceptually starts containing every positive integer, supporting `popSmallest()` (remove and return the current smallest member) and `addBack(num)` (re-insert `num` if it isn't already present).

**Example:** `popSmallest()` repeatedly returns `1, 2, 3, ...`; `addBack(1)` makes `1` available again for the next `popSmallest()`

**Constraints:** `1 <= num <= 1000`, at most `1000` total calls
