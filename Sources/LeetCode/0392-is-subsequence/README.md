# 392. Is Subsequence

**Difficulty:** Easy
**Tags:** Two Pointers, Array
**Status:** ✅ Completed

## Approach

Two pointers walking s and t; advance the s pointer only on a match, and check it reached the end of s.

- Space: O(1)
