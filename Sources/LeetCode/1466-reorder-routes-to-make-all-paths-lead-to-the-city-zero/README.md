# 1466. Reorder Routes to Make All Paths Lead to the City Zero

[LeetCode link](https://leetcode.com/problems/reorder-routes-to-make-all-paths-lead-to-the-city-zero/)

**Difficulty:** Medium
**Tags:** Graph, DFS
**Status:** ⬜ Not started

## Problem

`n` cities are connected by `n - 1` directed roads forming a tree (rooted conceptually at city 0). Return the minimum number of roads that must be reversed so every city can reach city `0`.

**Example:** `n = 6`, `connections = [[0,1],[1,3],[2,3],[4,0],[4,5]]` → `3`
**Example:** `n = 5`, `connections = [[1,0],[1,2],[3,2],[3,4]]` → `2`
**Example:** `n = 3`, `connections = [[1,0],[2,0]]` → `0`

**Constraints:** `2 <= n <= 5*10^4`, `connections.length == n - 1`, guaranteed to form a valid tree
