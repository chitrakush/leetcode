# 374. Guess Number Higher or Lower

[LeetCode link](https://leetcode.com/problems/guess-number-higher-or-lower/)

**Difficulty:** Easy
**Tags:** Binary Search
**Status:** ⬜ Not started

## Problem

A number between `1` and `n` has been picked. You may call a provided `guess(num)` API which returns whether your guess was too high, too low, or exactly right. Return the picked number.

**Example:** `n = 10`, picked `6` → `6`
**Example:** `n = 1`, picked `1` → `1`

**Constraints:** `1 <= n <= 2^31 - 1`, `1 <= pick <= n`
