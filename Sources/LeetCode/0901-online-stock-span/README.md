# 901. Online Stock Span

[LeetCode link](https://leetcode.com/problems/online-stock-span/)

**Difficulty:** Medium
**Tags:** Stack, Monotonic Stack
**Status:** ⬜ Not started

## Problem

Design a stock tracker that, for each day's `next(price)` call, returns the "span" — the number of consecutive days ending today (including today) whose price was less than or equal to today's.

**Example:** prices `100, 80, 60, 70, 60, 75, 85` → spans `1, 1, 1, 2, 1, 4, 6`

**Constraints:** `1 <= price <= 10^5`, at most `10^4` calls to `next`
