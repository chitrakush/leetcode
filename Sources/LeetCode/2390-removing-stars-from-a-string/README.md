**Difficulty:** Medium
**Tags:** Stack
**Status:** ⬜ Not started

## Problem

Given a string `s` of lowercase letters and `*` characters, repeatedly remove a `*` together with the closest non-star character immediately to its left. Return the resulting string once no stars remain.

**Example:** `s = "leet**cod*e"` → `"lecoe"`
**Example:** `s = "erase*****"` → `""`

**Constraints:** `1 <= s.length <= 10^5`, lowercase letters and `*` only, removal is always well-defined
