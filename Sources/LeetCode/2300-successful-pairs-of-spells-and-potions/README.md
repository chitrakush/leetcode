# 2300. Successful Pairs of Spells and Potions

**Tags:** Binary Search
**Status:** ⬜ Not started

## Problem

Given arrays `spells` and `potions` and a `success` threshold, a spell-potion pair succeeds if the product of their strengths is at least `success`. Return, for each spell, how many potions it succeeds with.

**Example:** `spells = [5,1,3]`, `potions = [1,2,3,4,5]`, `success = 7` → `[4,0,3]`
**Example:** `spells = [3,1,2]`, `potions = [8,5,8]`, `success = 16` → `[2,0,2]`

**Constraints:** `1 <= spells.length, potions.length <= 10^5`, `1 <= success <= 10^10`
