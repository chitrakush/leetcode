**Tags:** Tree, Binary Tree, DFS, Recursion

## Problem

Given the root of a binary tree and an integer `targetSum`, count the number of downward paths (parent to child, need not start at the root or end at a leaf) whose node values sum to `targetSum`.

**Example:** `root = [10,5,-3,3,2,null,11,3,-2,null,1]`, `targetSum = 8` → `3`
**Example:** `root = [5,4,8,11,null,13,4,7,2,null,null,5,1]`, `targetSum = 22` → `3`

**Constraints:** number of nodes in `[0, 1000]`, `-10^9 <= Node.val <= 10^9`, `-1000 <= targetSum <= 1000`
