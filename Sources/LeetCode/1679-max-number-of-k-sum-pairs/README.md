# 1679. Max Number of K-Sum Pairs

[LeetCode link](https://leetcode.com/problems/max-number-of-k-sum-pairs/)

**Difficulty:** Medium
**Tags:** Two Pointers, Array
**Status:** ⬜ Not started

## Problem

Given an integer array `nums` and an integer `k`, repeatedly pick two numbers from the array that sum to `k` and remove them. Return the maximum number of such operations you can perform.

**Example:** `nums = [1,2,3,4]`, `k = 5` → `2`
**Example:** `nums = [3,1,3,4,3]`, `k = 6` → `1`

**Constraints:** `1 <= nums.length <= 10^5`, `1 <= nums[i] <= 10^9`, `1 <= k <= 10^9`
