## Problem

Given the root of a binary tree, return its maximum depth — the number of nodes on the longest path from the root to any leaf.

**Example:** `root = [3,9,20,null,null,15,7]` → `3`
**Example:** `root = [1,null,2]` → `2`

**Constraints:** number of nodes in `[0, 10^4]`, `-100 <= Node.val <= 100`
