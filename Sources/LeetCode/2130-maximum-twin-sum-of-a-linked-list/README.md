## Problem

Given the head of a linked list with an even number of nodes `n`, node `i`'s "twin" is node `n - 1 - i`. The twin sum of a node is its value plus its twin's value. Return the maximum twin sum over the whole list.

**Example:** `head = [5,4,2,1]` → `6`
**Example:** `head = [4,2,2,3]` → `7`
**Example:** `head = [1,100000]` → `100001`

**Constraints:** even number of nodes in `[2, 10^5]`, `1 <= Node.val <= 10^5`
