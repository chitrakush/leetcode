# 724. Find Pivot Index

[LeetCode link](https://leetcode.com/problems/find-pivot-index/)

**Difficulty:** Easy
**Tags:** Prefix Sum, Array
**Status:** ✅ Completed

## Problem

Given an integer array `nums`, find the leftmost index whose left-side sum (excluding the index itself) equals its right-side sum. Return `-1` if there is none. Either side sums to 0 if it's empty.

**Example:** `nums = [1,7,3,6,5,6]` → `3`
**Example:** `nums = [1,2,3]` → `-1`
**Example:** `nums = [2,1,-1]` → `0`

**Constraints:** `1 <= nums.length <= 10^4`, `-1000 <= nums[i] <= 1000`
