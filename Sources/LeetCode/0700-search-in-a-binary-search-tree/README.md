## Problem

Given the root of a binary search tree and an integer `val`, return the subtree rooted at the node whose value equals `val`, or `null` if it doesn't exist.

**Example:** `root = [4,2,7,1,3]`, `val = 2` → `[2,1,3]`
**Example:** `root = [4,2,7,1,3]`, `val = 5` → `[]`

**Constraints:** number of nodes in `[1, 5000]`, `1 <= Node.val, val <= 10^7`, valid BST
