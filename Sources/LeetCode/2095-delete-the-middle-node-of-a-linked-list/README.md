# 2095. Delete the Middle Node of a Linked List

[LeetCode link](https://leetcode.com/problems/delete-the-middle-node-of-a-linked-list/)

**Difficulty:** Medium
**Tags:** Linked List
**Status:** ⬜ Not started

## Problem

Given the head of a singly linked list, delete the middle node — the node at index `⌊n / 2⌋` (0-indexed) where `n` is the number of nodes — and return the new head.

**Example:** `head = [1,3,4,7,1,2,6]` → `[1,3,4,7,1,6]`
**Example:** `head = [1,2,3,4]` → `[1,2,4]`
**Example:** `head = [2,1]` → `[2]`

**Constraints:** number of nodes in `[1, 10^5]`, `1 <= Node.val <= 10^5`
