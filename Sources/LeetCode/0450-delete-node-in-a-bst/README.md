# 450. Delete Node in a BST

[LeetCode link](https://leetcode.com/problems/delete-node-in-a-bst/)

**Difficulty:** Medium
**Tags:** Tree, Binary Search Tree
**Status:** ⬜ Not started

## Problem

Given the root of a binary search tree and a `key`, delete the node with that value (if present) while keeping the BST property intact, and return the (possibly new) root.

**Example:** `root = [5,3,6,2,4,null,7]`, `key = 3` → any valid BST missing the value `3` (e.g. `[5,4,6,2,null,null,7]`)
**Example:** same tree, `key = 0` (not present) → unchanged
**Example:** `root = []`, `key = 0` → `[]`

**Constraints:** number of nodes in `[0, 10^4]`, `-10^5 <= Node.val <= 10^5`, all values unique, valid BST
