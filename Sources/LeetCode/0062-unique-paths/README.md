**Tags:** Dynamic Programming

## Problem

A robot starts at the top-left corner of an `m x n` grid and can only move right or down. Return how many distinct paths lead to the bottom-right corner.

**Example:** `m = 3`, `n = 7` → `28`
**Example:** `m = 3`, `n = 2` → `3`

**Constraints:** `1 <= m, n <= 100`, the answer fits in a 32-bit integer
