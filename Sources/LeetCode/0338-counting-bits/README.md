# 338. Counting Bits

[LeetCode link](https://leetcode.com/problems/counting-bits/)

**Difficulty:** Easy
**Tags:** Bit Manipulation
**Status:** ⬜ Not started

## Problem

Given an integer `n`, return an array `ans` of length `n + 1` where `ans[i]` is the number of `1` bits in the binary representation of `i`, for every `i` from `0` to `n`.

**Example:** `n = 2` → `[0,1,1]`
**Example:** `n = 5` → `[0,1,1,2,1,2]`

**Constraints:** `0 <= n <= 10^5`
