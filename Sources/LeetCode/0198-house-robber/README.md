**Tags:** Dynamic Programming

## Problem

Given an array `nums` of money stashed in houses along a street, adjacent houses can't both be robbed (a connected alarm triggers). Return the maximum total that can be robbed.

**Example:** `nums = [1,2,3,1]` → `4`
**Example:** `nums = [2,7,9,3,1]` → `12`

**Constraints:** `1 <= nums.length <= 100`, `0 <= nums[i] <= 400`
