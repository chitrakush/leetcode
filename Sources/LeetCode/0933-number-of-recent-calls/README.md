# 933. Number of Recent Calls

[LeetCode link](https://leetcode.com/problems/number-of-recent-calls/)

**Difficulty:** Easy
**Tags:** Queue
**Status:** ⬜ Not started

## Problem

Design a `RecentCounter` class that tracks request timestamps and, for each call `ping(t)` (in strictly increasing order of `t`, milliseconds), returns how many requests — including this one — landed in the trailing window `[t - 3000, t]`.

**Example:** pings at `t = 1, 100, 3001, 3002` → returns `1, 2, 3, 3`

**Constraints:** `1 <= t <= 10^9`, calls arrive with strictly increasing `t`, at most `10^4` calls
