## Problem

Given `n`, return the number of ways to fully tile a `2 x n` board using `2x1` dominoes and any rotation of an L-shaped tromino, modulo `10^9 + 7`.

**Example:** `n = 3` → `5`
**Example:** `n = 1` → `1`

**Constraints:** `1 <= n <= 1000`
