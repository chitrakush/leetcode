# 1448. Count Good Nodes in Binary Tree

[LeetCode link](https://leetcode.com/problems/count-good-nodes-in-binary-tree/)

**Difficulty:** Medium
**Tags:** Tree, Binary Tree, DFS, Recursion
**Status:** ⬜ Not started

## Problem

Given a binary tree, a node `X` is "good" if no node on the path from the root down to `X` (inclusive) has a value greater than `X`'s. Return the count of good nodes.

**Example:** `root = [3,1,4,3,null,1,5]` → `4`
**Example:** `root = [3,3,null,4,2]` → `3`
**Example:** `root = [1]` → `1`

**Constraints:** number of nodes in `[1, 10^5]`, `-10^4 <= Node.val <= 10^4`
