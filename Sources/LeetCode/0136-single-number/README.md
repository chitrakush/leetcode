## Problem

Given a non-empty array where every element appears exactly twice except one, find the element that appears only once. Must run in linear time using constant extra space.

**Example:** `nums = [2,2,1]` → `1`
**Example:** `nums = [4,1,2,1,2]` → `4`
**Example:** `nums = [1]` → `1`

**Constraints:** `1 <= nums.length <= 3*10^4`
