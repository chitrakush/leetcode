## Problem

Given the root of a binary tree, where the root is at level 1 and each level down increases by 1, return the smallest level number whose node values sum to the largest total among all levels.

**Example:** `root = [1,7,0,7,-8,null,null]` → `2`
**Example:** `root = [989,null,10250,98693,-89388,null,null,null,-32127]` → `2`

**Constraints:** number of nodes in `[1, 10^4]`, `-10^5 <= Node.val <= 10^5`
