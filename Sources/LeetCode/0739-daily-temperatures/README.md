**Tags:** Stack, Monotonic Stack
**Status:** ⬜ Not started

## Problem

Given daily temperatures, for each day return the number of days you'd need to wait for a strictly warmer day; `0` if no warmer day ever comes.

**Example:** `temperatures = [73,74,75,71,69,72,76,73]` → `[1,1,4,2,1,1,0,0]`
**Example:** `temperatures = [30,40,50,60]` → `[1,1,1,0]`
**Example:** `temperatures = [30,60,90]` → `[1,1,0]`

**Constraints:** `1 <= temperatures.length <= 10^5`, `30 <= temperatures[i] <= 100`
