# 1431. Kids With the Greatest Number of Candies

[LeetCode link](https://leetcode.com/problems/kids-with-the-greatest-number-of-candies/)

**Difficulty:** Easy
**Tags:** Array, String
**Status:** ✅ Completed

## Approach

Find the current max, then for each kid check if their candies plus extras would reach or exceed it.

## Complexity

- Time: O(n)
- Space: O(n)
