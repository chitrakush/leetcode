## Problem

Given an integer array `nums` and an integer `k`, return the `k`th largest element in sorted order (not the `k`th distinct value).

**Example:** `nums = [3,2,1,5,6,4]`, `k = 2` → `5`
**Example:** `nums = [3,2,3,1,2,4,5,5,6]`, `k = 4` → `4`

**Constraints:** `1 <= k <= nums.length <= 10^5`, `-10^4 <= nums[i] <= 10^4`
