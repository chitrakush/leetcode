# 199. Binary Tree Right Side View

[LeetCode link](https://leetcode.com/problems/binary-tree-right-side-view/)

**Difficulty:** Medium
**Tags:** Tree, Binary Tree, BFS
**Status:** ⬜ Not started

## Problem

Given the root of a binary tree, imagine viewing it from the right side. Return the values of the nodes visible from that side, ordered from top to bottom.

**Example:** `root = [1,2,3,null,5,null,4]` → `[1,3,4]`
**Example:** `root = [1,2,3,4,null,null,null,5]` → `[1,3,4,5]`
**Example:** `root = [1,null,3]` → `[1,3]`

**Constraints:** number of nodes in `[0, 100]`, `-100 <= Node.val <= 100`
