# 605. Can Place Flowers

[LeetCode link](https://leetcode.com/problems/can-place-flowers/)

**Difficulty:** Easy
**Tags:** Array, String
**Status:** ✅ Completed

## Approach

Greedily plant a flower in every empty plot whose neighbors are also empty (or off the edge), counting as we go.

## Complexity

- Time: O(n)
- Space: O(n)
