# 2542. Maximum Subsequence Score

## Problem

Given equal-length integer arrays `nums1` and `nums2` and an integer `k`, choose `k` indices; the score of that choice is `(sum of chosen nums1 values) * (minimum of chosen nums2 values)`. Return the maximum possible score.

**Example:** `nums1 = [1,3,3,2]`, `nums2 = [2,1,3,4]`, `k = 3` → `12`
**Example:** `nums1 = [4,2,3,1,1]`, `nums2 = [7,5,10,9,6]`, `k = 1` → `30`

**Constraints:** `1 <= n <= 10^5`, `1 <= k <= n`
