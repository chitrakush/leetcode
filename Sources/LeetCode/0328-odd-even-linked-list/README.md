# 328. Odd Even Linked List

[LeetCode link](https://leetcode.com/problems/odd-even-linked-list/)

**Difficulty:** Medium
**Tags:** Linked List
**Status:** ⬜ Not started

## Problem

Given the head of a singly linked list, regroup the nodes so that all nodes originally at odd (1-indexed) positions come first, in order, followed by all nodes originally at even positions, in order — done in-place (`O(1)` extra space, `O(n)` time).

**Example:** `head = [1,2,3,4,5]` → `[1,3,5,2,4]`
**Example:** `head = [2,1,3,5,6,4,7]` → `[2,3,6,7,1,5,4]`

**Constraints:** number of nodes in `[0, 10^4]`, `-10^6 <= Node.val <= 10^6`
