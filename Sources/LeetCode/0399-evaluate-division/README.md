**Difficulty:** Medium
**Tags:** Graph, DFS

## Problem

You're given equations of the form `a / b = value` (each a known ratio between two variables) plus a list of queries `c / d`. Return the evaluated result for each query, or `-1.0` if it can't be derived from the given equations.

**Example:** `equations = [["a","b"],["b","c"]]`, `values = [2.0,3.0]`, `queries = [["a","c"],["b","a"],["a","e"],["a","a"],["x","x"]]` → `[6.0,0.5,-1.0,1.0,-1.0]`

**Constraints:** `1 <= equations.length <= 20`, `0.0 < values[i] <= 20.0`, `1 <= queries.length <= 20`
