## Problem

The Tribonacci sequence is defined by `T0 = 0`, `T1 = 1`, `T2 = 1`, and `T(n+3) = T(n) + T(n+1) + T(n+2)`. Given `n`, return `Tn`.

**Example:** `n = 4` → `4`
**Example:** `n = 25` → `1389537`

**Constraints:** `0 <= n <= 37`, the answer fits in a 32-bit integer
