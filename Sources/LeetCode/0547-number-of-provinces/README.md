# 547. Number of Provinces

**Difficulty:** Medium
**Tags:** Graph, DFS
**Status:** ⬜ Not started

## Problem

Given an `n x n` adjacency matrix `isConnected` for `n` cities (direct connections only), a province is a maximal group of cities reachable from each other. Return the total number of provinces.

**Example:** `isConnected = [[1,1,0],[1,1,0],[0,0,1]]` → `2`
**Example:** `isConnected = [[1,0,0],[0,1,0],[0,0,1]]` → `3`

**Constraints:** `1 <= n <= 200`, symmetric 0/1 matrix, diagonal is always `1`
