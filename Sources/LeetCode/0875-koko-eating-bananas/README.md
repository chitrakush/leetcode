**Difficulty:** Medium

## Problem

Koko has `n` piles of bananas and `h` hours before the guards return. Each hour she picks one pile and eats up to `k` bananas from it (finishing early if the pile has fewer). Return the minimum integer speed `k` that lets her finish every pile within `h` hours.

**Example:** `piles = [3,6,7,11]`, `h = 8` → `4`
**Example:** `piles = [30,11,23,4,20]`, `h = 5` → `30`
**Example:** same piles, `h = 6` → `23`

**Constraints:** `piles.length <= h <= 10^9`, `1 <= piles[i] <= 10^9`
