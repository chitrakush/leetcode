# 394. Decode String

**Difficulty:** Medium
**Tags:** Stack

## Problem

Decode a string encoded with the rule `k[encoded_string]`, meaning `encoded_string` is repeated `k` times; encodings may nest arbitrarily deep. Return the fully decoded string.

**Example:** `s = "3[a]2[bc]"` → `"aaabcbc"`
**Example:** `s = "3[a2[c]]"` → `"accaccacc"`
**Example:** `s = "2[abc]3[cd]ef"` → `"abcabccdcdcdef"`

**Constraints:** `1 <= s.length <= 30`, lowercase letters/digits/`[`/`]`, guaranteed a valid encoding
