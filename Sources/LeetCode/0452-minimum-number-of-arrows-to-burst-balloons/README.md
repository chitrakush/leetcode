# 452. Minimum Number of Arrows to Burst Balloons

[LeetCode link](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/)

**Difficulty:** Medium
**Tags:** Array, Sorting
**Status:** ⬜ Not started

## Problem

Each balloon spans a horizontal range `[xstart, xend]`. An arrow shot straight up bursts every balloon whose range it passes through. Return the minimum number of arrows needed to burst every balloon.

**Example:** `points = [[10,16],[2,8],[1,6],[7,12]]` → `2`
**Example:** `points = [[1,2],[3,4],[5,6],[7,8]]` → `4`
**Example:** `points = [[1,2],[2,3],[3,4],[4,5]]` → `2`

**Constraints:** `1 <= points.length <= 10^5`, `-2^31 <= xstart < xend <= 2^31 - 1`
