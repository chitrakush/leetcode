# 1268. Search Suggestions System

[LeetCode link](https://leetcode.com/problems/search-suggestions-system/)

**Difficulty:** Medium
**Tags:** Trie
**Status:** ⬜ Not started

## Problem

Given a list of `products` and a `searchWord` typed one character at a time, return — after each character typed — the up-to-3 lexicographically smallest products that currently share that typed prefix.

**Example:** `products = ["mobile","mouse","moneypot","monitor","mousepad"]`, `searchWord = "mouse"` → a list of suggestion-triples, one per character typed

**Constraints:** `1 <= products.length <= 1000`, sum of product lengths `<= 2*10^4`, `1 <= searchWord.length <= 1000`
