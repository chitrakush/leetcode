# 345. Reverse Vowels of a String

[LeetCode link](https://leetcode.com/problems/reverse-vowels-of-a-string/)

**Difficulty:** Easy
**Tags:** Array, String
**Status:** ✅ Completed

## Approach

Two pointers from both ends, skipping non-vowels, swapping vowels found on each side.

## Complexity

- Time: O(n)
- Space: O(n)
