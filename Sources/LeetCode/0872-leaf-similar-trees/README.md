# 872. Leaf-Similar Trees

[LeetCode link](https://leetcode.com/problems/leaf-similar-trees/)

**Difficulty:** Easy
**Tags:** Tree, Binary Tree, DFS, Recursion
**Status:** ⬜ Not started

## Problem

A tree's leaves, read left to right, form its "leaf value sequence." Given the roots of two binary trees, return `true` if they have the same leaf value sequence, even if the rest of the trees differ.

**Example:** two differently-shaped trees whose leaves read `6,7,4,9,8` on both sides → `true`
**Example:** `root1 = [1]`, `root2 = [2]` → `false`

**Constraints:** each tree has `1` to `200` nodes, `0 <= Node.val <= 200`
