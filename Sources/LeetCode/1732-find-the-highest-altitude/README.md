# 1732. Find the Highest Altitude

[LeetCode link](https://leetcode.com/problems/find-the-highest-altitude/)

**Difficulty:** Easy
**Tags:** Prefix Sum, Array
**Status:** ⬜ Not started

## Problem

A biker rides past `n + 1` points, starting at altitude 0. Given an array `gain` of length `n` where `gain[i]` is the net altitude change between point `i` and point `i + 1`, return the highest altitude reached anywhere along the trip.

**Example:** `gain = [-5,1,5,0,-7]` → `1`
**Example:** `gain = [-4,-3,-2,-1,4,3,2]` → `0`

**Constraints:** `1 <= gain.length <= 100`, `-100 <= gain[i] <= 100`
