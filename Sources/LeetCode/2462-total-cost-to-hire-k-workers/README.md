# 2462. Total Cost to Hire K Workers

[LeetCode link](https://leetcode.com/problems/total-cost-to-hire-k-workers/)

**Difficulty:** Medium
**Tags:** Heap (Priority Queue)
**Status:** ⬜ Not started

## Problem

Given a 0-indexed array `costs` of `n` worker costs, hire exactly `k` workers over `k` rounds. Each round, compare the cheapest of the first `candidates` remaining workers against the cheapest of the last `candidates` remaining workers (ties go to the smaller index), hire that one, and remove them from the pool. Return the total cost of all hires.

**Example:** `costs = [17,12,10,2,7,2,11,20,8]`, `k = 3`, `candidates = 4` → `11`
**Example:** `costs = [1,2,4,1]`, `k = 3`, `candidates = 3` → `4`

**Constraints:** `1 <= costs.length <= 10^5`, `1 <= k, candidates <= costs.length`
