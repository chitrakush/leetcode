## Problem

Senators in the Dota2 senate belong to Radiant (`'R'`) or Dire (`'D'`). Each round, in order, every still-active senator either bans one opposing senator (permanently removing their voting rights) or, if their party already controls all remaining votes, declares victory. Given the initial order `senate`, and assuming everyone plays optimally (banning the next opponent in line), return which party ultimately wins.

**Example:** `senate = "RD"` → `"Radiant"`
**Example:** `senate = "RDD"` → `"Dire"`

**Constraints:** `1 <= senate.length <= 10^4`, characters are `'R'` or `'D'`
