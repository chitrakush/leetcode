**Tags:** Hash Table

## Problem

Given an `n x n` integer matrix `grid`, count the number of pairs `(row i, column j)` such that row `i`, read left to right, is identical to column `j`, read top to bottom.

**Example:** `grid = [[3,2,1],[1,7,6],[2,7,7]]` → `1`
**Example:** `grid = [[3,1,2,2],[1,4,4,5],[2,4,2,2],[2,4,2,2]]` → `3`

**Constraints:** `1 <= n <= 200`, `1 <= grid[i][j] <= 10^5`
