# 283. Move Zeroes

[LeetCode link](https://leetcode.com/problems/move-zeroes/)

**Difficulty:** Easy
**Tags:** Two Pointers, Array
**Status:** ✅ Completed

## Approach

Two pointers: swap each non-zero element into the next open slot at the front, leaving zeros pushed to the back.

## Complexity

- Time: O(n)
- Space: O(1)
