**Difficulty:** Medium
**Tags:** Graph, DFS

## Problem

There are `n` rooms labeled `0` to `n-1`; room `0` starts unlocked and each room may contain keys (in `rooms[i]`) to other rooms. Starting from room `0`, return whether every room can eventually be visited.

**Example:** `rooms = [[1],[2],[3],[]]` → `true`
**Example:** `rooms = [[1,3],[3,0,1],[2],[0]]` → `false`

**Constraints:** `2 <= n <= 1000`, keys are valid room indices distinct within each room, no room contains a key to itself
