## Problem

Find all combinations of `k` distinct numbers from `1`–`9` that sum to `n`, where each combination is a set (order doesn't matter) and each number is used at most once across all combinations returned.

**Example:** `k = 3`, `n = 7` → `[[1,2,4]]`
**Example:** `k = 3`, `n = 9` → `[[1,2,6],[1,3,5],[2,3,4]]`
**Example:** `k = 4`, `n = 1` → `[]`

**Constraints:** `2 <= k <= 9`, `1 <= n <= 60`
