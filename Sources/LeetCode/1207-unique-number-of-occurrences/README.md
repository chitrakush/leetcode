# 1207. Unique Number of Occurrences

[LeetCode link](https://leetcode.com/problems/unique-number-of-occurrences/)

**Difficulty:** Easy
**Tags:** Hash Table
**Status:** ⬜ Not started

## Problem

Given an integer array `arr`, return `true` if every distinct value occurs a different number of times from every other distinct value (i.e. the occurrence counts are all unique).

**Example:** `arr = [1,2,2,1,1,3]` → `true` (counts are 3, 2, 1 — all distinct)
**Example:** `arr = [1,2]` → `false`
**Example:** `arr = [-3,0,1,-3,1,1,1,-3,10,0]` → `true`

**Constraints:** `1 <= arr.length <= 1000`, `-1000 <= arr[i] <= 1000`
