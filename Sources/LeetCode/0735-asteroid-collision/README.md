## Problem

Given an array `asteroids` where each value's magnitude is size and sign is direction (positive = moving right, negative = moving left), simulate collisions between asteroids moving toward each other: the smaller one explodes, equal sizes both explode, larger survives. Asteroids moving the same direction never meet. Return the array's final state.

**Example:** `asteroids = [5,10,-5]` → `[5,10]`
**Example:** `asteroids = [8,-8]` → `[]`
**Example:** `asteroids = [10,2,-5]` → `[10]`

**Constraints:** `2 <= asteroids.length <= 10^4`, `-1000 <= asteroids[i] <= 1000`, `asteroids[i] != 0`
