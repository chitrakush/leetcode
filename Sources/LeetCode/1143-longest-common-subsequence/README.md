## Problem

Given two strings `text1` and `text2`, return the length of their longest common subsequence — characters that appear in the same relative order in both, but need not be contiguous. Return `0` if there's no common subsequence.

**Example:** `text1 = "abcde"`, `text2 = "ace"` → `3`
**Example:** `text1 = "abc"`, `text2 = "abc"` → `3`
**Example:** `text1 = "abc"`, `text2 = "def"` → `0`

**Constraints:** `1 <= text1.length, text2.length <= 1000`, lowercase English letters
