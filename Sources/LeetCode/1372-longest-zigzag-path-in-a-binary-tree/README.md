# 1372. Longest ZigZag Path in a Binary Tree

[LeetCode link](https://leetcode.com/problems/longest-zigzag-path-in-a-binary-tree/)

**Difficulty:** Medium
**Tags:** Tree, Binary Tree, DFS, Recursion
**Status:** ⬜ Not started

## Problem

Starting from any node in a binary tree, a zigzag path alternates directions each step — left child, then right child, then left, and so on (or the mirror image) — with its length counted in edges. Return the length of the longest zigzag path anywhere in the tree.

**Example:** a specific tree layout → `3`
**Example:** `root = [1,1,1,null,1,null,null,1,1,null,1]` → `4`
**Example:** `root = [1]` → `0`

**Constraints:** number of nodes in `[1, 5*10^4]`, `1 <= Node.val <= 100`
