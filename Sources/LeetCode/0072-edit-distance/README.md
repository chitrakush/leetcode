## Problem

Given two strings `word1` and `word2`, return the minimum number of single-character insert, delete, or replace operations needed to transform `word1` into `word2`.

**Example:** `word1 = "horse"`, `word2 = "ros"` → `3`
**Example:** `word1 = "intention"`, `word2 = "execution"` → `5`

**Constraints:** `0 <= word1.length, word2.length <= 500`, lowercase English letters
