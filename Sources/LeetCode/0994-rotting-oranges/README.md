# 994. Rotting Oranges

[LeetCode link](https://leetcode.com/problems/rotting-oranges/)

**Difficulty:** Medium
**Tags:** Graph, BFS
**Status:** ⬜ Not started

## Problem

Given an `m x n` grid where each cell is empty (`0`), fresh (`1`), or rotten (`2`), every minute a fresh orange adjacent to a rotten one also rots. Return the minimum minutes until no fresh orange remains, or `-1` if some fresh orange can never rot.

**Example:** `grid = [[2,1,1],[1,1,0],[0,1,1]]` → `4`
**Example:** `grid = [[2,1,1],[0,1,1],[1,0,1]]` → `-1`
**Example:** `grid = [[0,2]]` → `0`

**Constraints:** `1 <= m, n <= 10`, cell values are `0`, `1`, or `2`
