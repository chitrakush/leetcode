# 746. Min Cost Climbing Stairs

**Difficulty:** Easy
**Tags:** Dynamic Programming
**Status:** ⬜ Not started

## Problem

Given an array `cost` where `cost[i]` is the price of stepping on stair `i`, you can start on step `0` or `1`, and each move advances one or two steps. Return the minimum total cost to get past the top of the staircase.

**Example:** `cost = [10,15,20]` → `15`
**Example:** `cost = [1,100,1,1,1,100,1,1,100,1]` → `6`

**Constraints:** `2 <= cost.length <= 1000`, `0 <= cost[i] <= 999`
