## Problem

Given a string of digits `2`–`9`, return every possible letter combination it could represent under the standard phone-keypad mapping, in any order.

**Example:** `digits = "23"` → `["ad","ae","af","bd","be","bf","cd","ce","cf"]`
**Example:** `digits = ""` → `[]`
**Example:** `digits = "2"` → `["a","b","c"]`

**Constraints:** `0 <= digits.length <= 4`
