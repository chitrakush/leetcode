## Problem

Two strings are "close" if one can be turned into the other using any number of: (1) swapping any two characters within the string, or (2) globally relabeling one existing character as another (applied consistently everywhere it and its swap partner occur). Return whether `word1` and `word2` are close.

**Example:** `word1 = "abc"`, `word2 = "bca"` → `true`
**Example:** `word1 = "a"`, `word2 = "aa"` → `false`
**Example:** `word1 = "cabbba"`, `word2 = "abbccc"` → `true`

**Constraints:** `1 <= word1.length, word2.length <= 10^5`, lowercase English letters only
