# 334. Increasing Triplet Subsequence

[LeetCode link](https://leetcode.com/problems/increasing-triplet-subsequence/)

**Difficulty:** Medium
**Tags:** Array, String
**Status:** ✅ Completed

## Approach

Track the smallest and second-smallest values seen so far; any number beating both completes an increasing triplet.

## Complexity

- Time: O(n)
- Space: O(1)
