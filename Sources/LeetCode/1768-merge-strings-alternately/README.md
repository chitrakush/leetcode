# 1768. Merge Strings Alternately

[LeetCode link](https://leetcode.com/problems/merge-strings-alternately/)

**Difficulty:** Easy
**Tags:** Array, String
**Status:** ✅ Completed

## Approach

Walk both strings with two pointers, appending one character from each in turn, then draining whichever string is longer.

## Complexity

- Time: O(n + m)
- Space: O(n + m)
